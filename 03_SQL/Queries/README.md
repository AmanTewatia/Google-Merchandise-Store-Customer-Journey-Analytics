# SQL Analysis

This folder contains the SQL analysis performed on the Google Merchandise Store Customer Journey dataset.

## Objectives

- Explore customer journey data.
- Analyse marketing campaign performance.
- Evaluate conversion behaviour.
- Measure revenue performance.
- Identify business growth opportunities.
- Generate insights for executive decision-making.

## SQL Skills Demonstrated

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE Statements
- JOINS
- Common Table Expressions (CTEs)
- Window Functions
- Subqueries
- Date Functions
- Business KPI Calculations
